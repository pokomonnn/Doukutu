ダンジョン用・自然会話 / 独り言 セリフパック v1.0
=======================================================
対象：2D横スクロールのダンジョン内。町のクリック式画面は対象外。
収録：NPC・Enemy同士の自然会話 350本 / 独り言 250本 / 計600パターン。

【内訳】
・冒険者同士の掛け合い：80
・盗賊同士の掛け合い：80
・ドワーフ同士の掛け合い：80
・異なる派閥間の掛け合い：60
・救出対象・一般人同士の掛け合い：50
・冒険者の独り言：50
・盗賊の独り言：50
・ドワーフの独り言：50
・救出対象・非戦闘員の独り言：50
・敵対者・警戒状態の独り言：50

【世界観の取り扱い】
・ステージ1〜3には冒険者・盗賊・ドワーフが混在する。ステージの固定派閥にはしない。
・ステージ1：旧居住区／ステージ2：工房区／ステージ3：聖堂区。
・冒険者と盗賊は通常敵対。停戦成立後の会話のみ、平穏な掛け合いを許可する。
・ドワーフは冒険者・盗賊どちらとも原則中立。
・町から集められた職人、商人、医者などの救出対象がダンジョン内にいる。
・貴族の妻、慈悲の女神、最下層の真相、古王国滅亡の核心は明かさない。
・ステージ4の無言で佇む存在には会話・独り言を割り当てない。

【導入済みシステムとの関係】
・STEP5（DialogueAmbientTalk2D）での二人会話を想定した台本。
・単独発話は既存の自動セリフ・発話機構に載せる想定だが、
  「独り言」のトリガーが現行コードに実装済みかはソース未照合のため要確認。
・STEP3の戦闘用セリフは今回含まない。戦闘台本300パターンは次回制作対象。
・各レコードは独自の編集用TXT記法。Dialogue Studio 2Dへそのまま
  自動インポートできると保証する形式ではない。現行C#で必要に応じて変換。

【推奨再生ルール（脚本側提案。コード仕様ではない）】
・掛け合い：二人とも生存・非戦闘・会話可能・近距離にいる場合のみ。
・独り言：一人で発話可能。巡回・作業・休憩・警戒の適切なモードで使用。
・会話中に戦闘が始まれば中断し、戦闘専用セリフの再生を優先。
・イベント台詞 > ミッション会話 > 戦闘セリフ > 環境会話の優先順位を推奨。
・同時発話による大量の吹き出しを防ぐため、画面内同時再生数を制限。
・NPC単位・ペア単位でクールダウンを設け、直前と同じIDを避ける。
・掛け合い推奨：共通クールダウン120〜240秒、独り言90〜180秒。
  実際の値はゲームスピードや同時NPC数に合わせて調整する。
・「性格目安」は演技・発話者選定の参考タグであり、条件分岐の確定値ではない。
・特定の職業が必要な台詞は、その職業NPCに割り当てる。

【読み方】
AMB_ADV_001：冒険者グループの掛け合い1番
AMB_CROSS_001：異派閥グループの掛け合い1番
SOLO_BND_001：盗賊グループの独り言1番

【パターンの数え方】
掛け合い1本＝A/B（ときどきA）の一往復以上。独り言1本＝一つの発言。
同じ組み合わせのNPCで話者役を入れ替えることは別パターンに数えない。
舞台に合う分岐条件は話題や場面に応じて調整可能。

【注意】
このパックは町での通常会話、選択肢会話、取引会話、クエスト台本は含まない。
現在使用中の Dialogue Studio 2D STEP1〜STEP5 導入済みを前提にした脚本資料。

ステージ2クエスト：Unity実装メモ／進行・整合性テスト案
※このファイルに記したコード識別子は仮名。現在のプロジェクトにある既存APIの実在は確認していない。

【一、最小で必要なセーブ状態】
S2M01_Started / S2M01_ClueFound / S2M01_Completed / S2M01_RewardTaken
S2S01_Started / S2S01_FoundOriginal / S2S01_FoundAlternative / S2S01_Resolution / S2S01_Completed
S2S02_Started / S2S02_LedgerFound / S2S02_PermitIssued / S2S02_Completed
S2S03_Started / S2S03_BearingFound / S2S03_ValveFound / S2S03_GearFound / S2S03_Installed / S2S03_WaterRestored / S2S03_Completed
Bandits_PlayerRelation = Hostile / Neutral / Friendly
ButlerAppeared（他メインと共有）
STAGE4_UNLOCKED（他メインと共有）

【二、状態遷移】
MAIN初の手掛かり取得 → ButlerAppearedを町で反映（Town初回導入以後）。妻の話は追加しない。
MAIN3件の報告完了 → STAGE4_UNLOCKED = true。
S1-S02停戦成立 → Bandits_PlayerRelation=Neutral。ステージ2の盗賊クエスト受注可。
S2-S02報告完了 → Bandits_PlayerRelation=Friendly。ただし冒険者対盗賊は敵対のまま。
S2-S03水門起動 → ステージ2内の流水・水車アニメーションを永続ON。報酬はグレンへの報告時に一度だけ。

【三、Unityへの反映方針】
・メインの「起動手順」、倉庫「荷物目録」、町長「搬入許可証」は証拠品フラグ管理でもよい。アイテム取得操作の演出は残す。
・「冒険者の補給箱」「保存食と救護用品」、水路の3部品はインベントリ運搬の楽しさを作れる。ただし所持品が満杯なら調査地点に品物を残し、拾い直せること。
・既存ItemDataとミッション納品処理を使う場合、通常アイテムの売却・床ドロップ・装備の有無によって進行不能にならないか確認する。
・ステージ2の固定調査地点は、ランダム配置のItemBoxと別の一度だけの証拠品として管理する。
・NPC救出で町施設が強くなる既存の仕組みはそのまま。派閥ミッションの報酬Gは新しい強化システムの必須要件にしない。
・各派閥の代表NPCは、必要ならステージごとに同じ名前で登場できる。時間的な違和感が強ければ各拠点の連絡員に台詞を引き継がせる。
・町の会話イベントは「報告対象のメイン/サブがあるか」を先に判定。町長の初回案内を飛ばした状態の報告も処理できるようにする。
・フラグや報酬の保存タイミングはシーンをまたぐ直前にも確認。探索から町へ帰還した後に巻き戻らないこと。

【四、Dialogue台本の読み方】
大文字ID：会話ノード名の提案（実際のユニークIDはS2M01_等の名前空間を付与して重複回避可）
［選択肢］：「プレイヤーが選ぶ表示文」→ 次ノードのID
［地の文］：探索・アイテム回収・演出用の画面文章
［処理］：クエスト状態変更または報酬処理。会話データへ直接文字列として表示しないこと。
END：会話を閉じる。必要なら任意共通の終了ノードへ変換する。

【五、テスト項目】
[ ] ステージ2を最初に訪れ、メイン手掛かりを取ってから町長へ報告できる。
[ ] ステージ1・3より先にS2メイン完了してもステージ4は解放されない。
[ ] 3件すべてのメインを完了したときのみステージ4が解放される。
[ ] 先に別ステージで執事が出現していた場合、執事の初回自己紹介が重複しない。
[ ] 執事は妻・女神・死者の情報を話さない。
[ ] ロアンにはA/Bいずれか1つ納品すれば達成でき、報酬は二重に出ない。
[ ] 盗賊敵対中にも冒険者の補給クエストを完了できる。
[ ] Bルートでも盗賊との停戦を勝手に成立させない。
[ ] S1-S02未達成でも、S2マップ探索とメインに支障がない。
[ ] S1-S02後、バルドからS2-S02を受注できる。
[ ] 町長の許可証を何度も受け取れない。クエスト達成・友好変化は一度きり。
[ ] 主人公と盗賊が友好になっても、冒険者対盗賊はステージ3まで敵対を維持。
[ ] S1-S03未達成でも水路クエストを受けられる。後から設計図を回収できる。
[ ] 水路の3部品が1つ足りない状態では工事・水門解放ができない。
[ ] 部品が揃えば工事でき、水門を開けば水車が回る。
[ ] 水路復旧後にシーンを離れ、戻っても水車・流水が正しく復元される。
[ ] インベントリ満杯・死亡・中断・再開でクエスト必須品を失っても回復手段がある。
[ ] 取得済みの証拠品を再調査してもアイテム・報酬が無限増殖しない。
[ ] どのクエストにも、妻・女神・死者の真相・滅亡の直接説明が混入していない。

【六、演出負担の節約】
町長・ロアン・バルド・グレンは既存の会話UIと立ち絵を利用する想定。
水車は回転Sprite差分＋流水Sprite＋水音だけで成立。修理作業は金属音と数行の台詞で表現可能。
倉庫・配給庫・機械室は旧工房区の既存背景に固定インタラクトを追加して表現できる。
報酬額、細かい交換レート、好感度の整数値、敵の特殊AIはこのパックでは未確定とする。
